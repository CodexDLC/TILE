Read:
- `docs/design/README.md`

Use this skill for:
- Django template work
- HTML/CSS implementation
- component design
- UI refinements for the public site

Core rules:
- Follow the Atlas editorial tone, not generic SaaS patterns.
- Keep the warm neutral palette, bronze accent, and forest dark sections.
- Preserve the typography hierarchy built around Fraunces, Inter, and Playfair Display Italic.
- Use restrained motion and subtle radii.
- Reuse patterns from `docs/design/preview/` and `docs/design/ui-kit/web/` before inventing new components.

Important:
- The prototypes are static references only.
- Production pages must still be implemented as DB-driven pages and reusable section components.
