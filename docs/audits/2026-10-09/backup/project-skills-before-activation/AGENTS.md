# Atlas / TALE — правила работы агентов

Внутреннее имя репозитория и Python-проекта — `atlas`. Публичный бренд — **TALE** (Travel Atlas of Local Experiences).

## Правила проекта

Перед изменениями загрузить проектные инструкции из `docs/agent-skills/*/SKILL.md` согласно project-skill-loader. Правила применяются к соответствующей области работы; инструкции, упоминающие Lily, использовать только там, где они соответствуют фактическому устройству Atlas.

Сохранять пользовательские незакоммиченные изменения. Следовать актуальному объёму задания пользователя; наличие будущей функции в ТЗ или плане не означает разрешения реализовать её сейчас.
