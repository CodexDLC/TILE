# Передача TALE автору

Обновлено: 2026-10-09. Автор работает с собственным Codex и поручает ему запуск и технические действия обычными словами. Эта запись — состояние подготовки, а не доказательство запуска на новом компьютере.

## Согласовано владельцем

- Работа автора ведётся в `develop`; `main` содержит исходную сохранённую точку передачи `3cc94d7`.
- Локально используются SQLite и фотографии на диске, без обязательного Docker.
- Код передаётся через приватный GitHub-репозиторий; готовые резервные архивы — через Syncthing. Живую базу и `.git` между компьютерами не синхронизировать.
- Первую настройку разработчик выполняет вместе с агентом. Автору не требуется самостоятельно выполнять команды.
- Предпочтение для её Codex: Sol — основной исполнитель и приёмка, Luna — простые изолированные поручения. Мелкие действия выполнять без помощника. Настройка моделей относится к её установке Codex и не применяется этим файлом к каждому агенту. Доступность моделей и действующие глобальные правила проверяются на новом компьютере; внутренние помощники используют общий лимит аккаунта.

## Известные ограничения

Текущий `pyproject.toml` ожидает шесть editable-библиотек по `../../codex_tools/…`. Исходники переехали, а старое окружение хранит прежние абсолютные пути. Штатный запуск Atlas в этой подготовке не считается проверенным до исправления окружения отдельным шагом.

Для текущего сайта необходим ещё не выпущенный код `codex-django` (`messaging`, `cabinet.resources`). Установка последнего доступного на дату проверки `codex-django==0.6.6` не заменяет его. Если CLI выпускается как `0.4.0`, нужно согласовать существующие ограничения `<0.4.0` в Atlas и библиотечном extra.

Проектная SQLite-база и media не переключаются вместе с Git-ветками. `git pull` и откат коммита не являются восстановлением материалов.

## Проверено при подготовке

На Python 3.13 и 3.14 выполнены синтетические тесты утилиты: 6 успешно, 1 пропущен из-за отсутствия разрешения создавать символические ссылки в Windows. Проверены сохранение исходных данных, полный цикл создания/проверки/восстановления, запрет перезаписи, повреждённый архив, опасные имена ZIP, относительные пути с пробелами и пустая media-папка. Проверка запрета символических ссылок реализована, но её реальный файловый тест в этой среде не выполнен.

Ruff check и format --check для новой утилиты прошли. Локальные ссылки документации, заголовок нового навыка и подключение из AGENTS.md проверены. Рабочая база и фотографии не использовались; запуск сайта, доставка Syncthing и восстановление на компьютере автора ещё не проверены.
