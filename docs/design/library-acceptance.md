## Реализовано

- Главная: книжные полки по существующим регионам; каждая книга ведёт по прежнему URL города.
- Компьютер / планшет: вертикальные книги; 0–3 опубликованных материала — тонкая, 4–11 — средняя, от 12 — широкая. Для полных томов используются предоставленные изображения, фото города или монограмма. Исходные изображения автора сохранены.
- Телефон менее 768 px: горизонтальные стопки, без барельефа, с горизонтальными названиями и счётчиком историй.
- Поиск по названиям города RU/DE/EN, выбор региона, сброс и каталог по 24 города на странице. Все формы работают без дополнительного JavaScript. Общий поиск историй и список последних материалов сохранены.
- Счётчик учитывает опубликованные дочерние STORY/PLACE городской Page — тот же состав, который открывается в существующем списке города. Новые правила публикации и схема не вводились.

## Проверено

- 39 тестов, 6 subtests: content, публичные маршруты, сборка. Отдельная проверка 540 городов даёт 23 страницы, последняя содержит 12 книг; фильтр сохраняется. Права редактора и существующий читательский путь входят в проверенный набор content.
- Ruff для изменённых Python-файлов и `manage check --settings=atlas.core.settings.test` — без ошибок. Сборка `manage compile_assets` выполнена через установленный `.venv/Scripts/python.exe`; `uv.exe` недоступен из-за отказа ОС, версии пакетов не менялись.
- Браузер Chrome / Playwright: ширины 1440, 768, 390, 320 px; нет горизонтальной прокрутки страницы, книги имеют достаточную область нажатия. Поиск → книга → город, фильтр региона, пустая выдача и сброс, страницы каталога, переключение RU → DE с сохранением фильтра, открытие меню / Escape / возврат фокуса работают.
- Подписи и счётчики помещаются внутри книг, изображения загружаются; JavaScript page errors отсутствуют. Предыдущие скомпилированные переводы сохранены, новые строки доступны на трёх языках.
- Локальная главная `http://127.0.0.1:8000/ru/` отвечает 200 и использует новую библиотеку. В проверенной локальной базе нет City с опубликованной связанной городской Page: отображается честное пустое состояние. Демонстрационные данные в рабочую базу не добавлялись.

## Ограничения

Точное расстояние между городами и тематические подборки не реализованы, не показаны неработающими кнопками. City не содержит координат; выбор механизма соседства — отдельный шаг. Это не проверка физического телефона или полноценная сертификация доступности.

Visual lint выполнен на desktop/mobile. Исправлены найденные мелкие подписи, путь фоновой текстуры после CSS-сборки и декоративное расширение полки. Оставшиеся предупреждения: эвристический overflow декоративных знаков и намеренно обрезанных изображений (aria-hidden); контраст существующих карточек / footer на фонах, которые эвристика не разрешает полностью. Они не объявлены успешным аудитом WCAG. Google Fonts блокируется сетью инструмента, снимки показывают запасные шрифты; существующий favicon возвращает 404. Внешнее размещение и публичный деплой не выполнялись.

Проверены затронутые проектные навыки публичных страниц, оформления, архитектуры и локальной работы: границы публикации / запуска остаются актуальными; библиотечные API и рабочие данные не менялись. Посторонние пользовательские изменения сохранены.
