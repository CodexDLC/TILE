# Заявки разработчику

Здесь авторские задачи, для которых нужно отдельное решение об изменении схемы данных. Создавайте один Markdown-файл на задачу с коротким понятным именем. Используйте [шаблон](TEMPLATE.md); не записывайте сюда вымышленные заявки.

Заявка фиксирует проблему и предлагаемый объём. Она не разрешает менять модели, миграции или рабочую базу. После явного решения разработчика обновите статус и укажите, что именно согласовано.
