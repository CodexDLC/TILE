# OmniRoute: проверенная настройка и границы

## Приоритет: проверенный бесплатный API через OmniRoute

Порядок владельца: подходящий подтверждённый бесплатный API через OmniRoute → официальный Antigravity CLI → внутренние исполнители Luna/Sol Codex. Это правило выбора исполнителя имеет приоритет над таблицей внутренних моделей. Мелкие ответы и завершающие правки выполнять локально, когда делегирование дороже работы.

Если в инструментах текущего чата доступен MCP omniroute, сначала рассмотреть omniroute_route_request для ограниченного анализа текста, документации, ревью или подготовки кода. В проверенной настройке ключ codex-free-mcp разрешает только модель openrouter/openrouter/free и подключение OpenRouter. Не заменять её на openrouter/auto или платную модель. OpenRouter free выбирает разные бесплатные модели; качество каждого результата проверять. Квота исчерпана или задача не подходит — переходить к официальному Antigravity CLI, без импорта подписки в OmniRoute. Не перепроверять все провайдеры перед каждой задачей.

Передавать model="openrouter/openrouter/free", messages с нужным контекстом, role из analysis/review/coding/planning, budget=0, stream=false. Проверенный короткий вызов вернул ответ и cost=0; ключ отклонил модель вне списка (HTTP 403). Реальная поддержка задач с инструментами/проектными файлами через Omni Skills пока не проверена: считать этот путь исполнителем текстовых поручений, а не самостоятельным файловым агентом.

В Codex зарегистрирован локальный Streamable HTTP MCP http://127.0.0.1:20128/api/mcp/stream с шестью разрешёнными инструментами: route_request, get_health, check_quota, cost_report, get_session_snapshot, tool_search (все с префиксом omniroute_). Не вызывать управляющие write-инструменты. Для появления подключения в существующей сессии может требоваться перезапуск приложения; если инструментов нет, сообщить это, не притворяться, что MCP уже доступен. Официальный CLI и REST-проверка не доказывают подключение инструментов текущего чата.

Установленный ключ хранится в ~/.codex/secrets/omniroute-mcp.dpapi с шифрованием Windows пользователя. Настроенный http_headers_helper получает его при подключении. Не читать/выводить токен, не вставлять его в промпты и отчёты. Не менять ключ, allowlist или транспорт без поручения владельца. Разговорная память OmniRoute включена 03.10.2026: SQLite/FTS5, до 512 токенов внедрённого контекста, retention 30 дней, без внешних embeddings/rerank. Нативный MCP вернул синтетический маркер из памяти; тестовая запись удалена. Память относится к запросам через OmniRoute и не импортирует историю Codex/Antigravity. Отдельный ключ — граница проекта/пользователя: одинаковый key факта в двух sessionId одного владельца обновил одну запись; не обещать изоляцию сессий. Перед отправкой учитывать, что подходящие воспоминания попадут внешней модели. Не сохранять секреты. Проектные файлы остаются основным источником состояния. Полный автоматический цикл извлечения фактов ещё не принят; установленных Omni Skills нет, файловый/tool-loop не проверен.
