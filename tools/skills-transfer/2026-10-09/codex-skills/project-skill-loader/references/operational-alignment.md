# Keeping operational skills aligned

Check for outdated instructions after changes to code, database schema, catalog entries, meaningful data, validation, permissions, statuses, API contracts or report calculations. Inspect only skills and references affected by the change; a full skills audit is unnecessary for ordinary work.

When instructions are stale, identify the skill path and section, the changed behavior, and the replacement instruction or example. Check both local-operation and API-operation guidance where applicable, keeping shared domain rules in one place. Identify maintained mirrors without assuming they synchronize automatically. Distinguish implemented behavior from planned functionality.

Do not silently rewrite business rules, update unrelated global skills or expand implementation scope. Project skills guide the agent but do not replace server-side validation and access controls. The main agent accepts any delegated alignment check.
